# Figma 助手说明

> 状态：历史侧向工具说明，不属于当前 Drass 主项目文档入口。

这份文档对应的是仓库中一组与 Figma 设计分析、GitHub Issue 生成相关的辅助脚本。它不是当前 Drass 主系统的核心功能说明，也不应再作为项目主 README 的补充入口使用。

## 当前定位

Figma 相关内容应被理解为：

- 历史或侧向工具
- 可能仍可复用的辅助脚本
- 与主系统前后端、RAG、部署链路无直接绑定的能力

## 为什么降级处理

过去这份文档的问题在于：

1. 它很容易让人误以为 Drass 当前主线是 “Figma UI 开发助手”
2. 它包含单独的项目叙事、目录结构和启动方式
3. 它会干扰当前主项目入口的判断

## 当前建议

如果后续确实还要保留 Figma 相关能力，建议：

1. 单独归档到 `docs/archive/` 或独立子目录说明
2. 不再放在仓库顶层作为主入口文档之一
3. 与当前 Drass 主系统文档完全分离
